# 이슈 / PR 개발 계획

아래 번호는 계획 순서이며 GitHub 이슈 번호가 아닙니다. 원칙은 한 이슈에 한 PR입니다.
실제 데이터 검증 결과에 따라 너무 큰 변경은 더 나눌 수 있습니다.

| 순서 | 범위 | 완료 조건 / 필요한 자료 |
|---|---|---|
| 1 (구현) | 구조·입출력 계약·데이터 검사 | 원본을 변경하지 않는 세션/지도 패키지 검사, 합성 입력 오류 테스트 |
| 2 (구현) | UFLD v2 검출 | 공식 구현·가중치로 실제 픽셀 좌표·오버레이 출력; 공개 샘플 실행 검증, 팀 좌우 시야 평가는 별도 |
| 3 | 카메라 보정·시각 정렬·좌우 융합 | 실제 장비·영상·보정 측정값으로 좌표 변환 오차와 동기화 성능 확인 |
| 4 | HD Map 조사·후보 차로 입력 | 실제 지도 CRS·geometry·필드 확인, 좌표 변환과 후보 기하 입력 구현 |
| 5 | 기하 기반 차로 추정 | 후보 점수/차로 결정 분리, UNKNOWN과 시간적 안정화, 실측 평가 |
| 6 | RF 학습·비교 | 세션 분리 정답 데이터로 기준선 대비 정확도·오판·재인식 지연 비교 |
| 7 | App 연동 | 팀이 실행 위치·통신·역할·활성화 시점을 결정한 후 연결 |

3과 4는 각각 자료가 준비되는 순서대로 진행할 수 있습니다. 5는 두 결과가 필요하고,
6은 실제 정답 데이터가 있어야 진행합니다. 현재 수정 범위는 1~2입니다. UFLD 검출 실행과
실측 차로 추정 정확도는 구분합니다. RF·지도 매칭은 아직 구현하지 않았습니다.
